# Device guide media

Illustrative stills used in the in-call device tutorial. Photos are from
[Unsplash](https://unsplash.com) (free to use; no permission required).

| Slug           | Intended subject            | Source style |
| -------------- | --------------------------- | ------------ |
| thermometer    | Medication / clinical still | Unsplash     |
| blood-pressure | Clinical / care setting     | Unsplash     |
| pulse-ox       | Healthcare / monitoring     | Unsplash     |
| glucose        | Clinical equipment          | Unsplash     |
| weight-scale   | Fitness / scale context     | Unsplash     |

Demo videos are optional. When `demo.mp4` is missing, the UI shows the hero
image with a “Demo video placeholder” caption so the tutorial flow still works.
Drop a short silent MP4 into each device folder as `demo.mp4` to enable playback.
